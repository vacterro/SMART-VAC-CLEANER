- Do not weaken blacklist, candidate-identity, owner/service, exclusion, or current per-tree boundary checks; this is an additional outer authority boundary.

- Do not "repair" an already INVALID config automatically by overwriting unrelated policy; existing fail-closed forensic behavior should remain.

VERIFY:
